# ХОЧУ! — мой вишлист

Персональный адаптивный вишлист, созданный в Figma Make и опубликованный через GitHub Pages.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Публикация на GitHub Pages выполняется автоматически после отправки изменений в ветку `main`.
